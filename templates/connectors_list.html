How to connect in Claude

  1. In Claude (web or iOS): Settings → Connectors → Add custom connector.
  2. Set the server URL to {{ instructions.mcp_url }}
  3. Expand Advanced settings and paste the connector's Client ID and Client Secret (shown once above).
  4. Connect — Claude will send you to Conduct to approve, then the job tools appear.

Conduct advertises its OAuth endpoints automatically (authorize: {{ instructions.authorize_url }}, token: {{ instructions.token_url }}). If the URL above is localhost, set CONDUCT_PUBLIC_URL to your public tunnel so Claude can reach it.
